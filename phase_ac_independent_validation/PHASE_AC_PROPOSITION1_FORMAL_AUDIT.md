## 1. Formal Mathematical Statement

Proposition 1 in the ROUTE/IQ framework states:

> **Proposition 1 (Incumbent-Preserving Non-Degradation & Feasibility Guarantee):**  
> Let $R_{\text{inc}} = (T_{A,\text{inc}}, T_{B,\text{inc}})$ be a known feasible two-vehicle fleet route covering customer set $S$ with payload demands $d_i$, satisfying $\sum_{i \in T_k} d_i \le Q_k$ for $k \in \{A, B\}$.  
> Let $R_{\text{cand}} = (T_{A,\text{cand}}, T_{B,\text{cand}})$ be an unconstrained candidate bipartition produced by any generator $\mathcal{G} \in \{\text{QAOA}, \text{Tabu}, \text{KL}, \text{Random}\}$.  
> Let $\mathcal{V}(R)$ denote deterministic Algorithmic Variable Neighborhood Descent refinement, and let $C(R) = \text{Length}(T_A) + \text{Length}(T_B)$.  
> The acceptance operator $\Phi(R_{\text{cand}}, R_{\text{inc}})$ is defined by:
> $$\Phi(R_{\text{cand}}, R_{\text{inc}}) = \begin{cases} \mathcal{V}(R_{\text{cand}}) & \text{if } \text{Coverage}(R_{\text{cand}}) \wedge \text{Capacity}(R_{\text{cand}}) \wedge [C(\mathcal{V}(R_{\text{cand}})) < C(\mathcal{V}(R_{\text{inc}})) - \epsilon] \\ \mathcal{V}(R_{\text{inc}}) & \text{otherwise} \end{cases}$$
> Then:
> 1. $C(\Phi(R_{\text{cand}}, R_{\text{inc}})) \le C(\mathcal{V}(R_{\text{inc}}))$ (Monotonic Non-Degradation).
> 2. $\text{Capacity}(\Phi(R_{\text{cand}}, R_{\text{inc}})) = \text{True}$ (100% Feasibility).

## 2. Audit of the Executable Implementation

The implementation in [`Proposition1Guardrail.validate_and_filter()`](file:///d:/UROP/smart-delivery-route-optimization/phase_ab_cooperative_optimization_engine/engine/proposition1_guardrail.py) was audited line-by-line:

```python
# 1. Customer Coverage Validation
cand_all = candidate_tour_a + candidate_tour_b
if set(cand_all) != expected_customers or len(cand_all) != N:
    return {"accepted": False, "rejection_reason": "INVALID_CUSTOMER_COVERAGE", ...}

# 2. Capacity Constraint Validation
qa = sum(demands[n - 1] for n in candidate_tour_a)
qb = sum(demands[n - 1] for n in candidate_tour_b)
if qa > cap_a or qb > cap_b or qa == 0 or qb == 0:
    return {"accepted": False, "rejection_reason": "CAPACITY_CONSTRAINT_VIOLATION", ...}

# 3. Route Evaluation & VND Optimization
cand_opt = AlgorithmicVND.optimize_fleet_routes(candidate_tour_a, candidate_tour_b, demands, cap_a, cap_b, dist_matrix)
inc_opt = AlgorithmicVND.optimize_fleet_routes(incumbent_tour_a, incumbent_tour_b, demands, cap_a, cap_b, dist_matrix)

# 4. Acceptance Filter
if d_cand < d_inc - tolerance:
    return {"accepted": True, "final_distance": round(d_cand, 2), ...}
else:
    return {"accepted": False, "final_distance": round(d_inc, 2), ...}
```

### Verification Against Mathematical Requirements
1. **Capacity Feasibility:** Checked explicitly prior to VND. Any overage ($qa > \text{cap}_a$ or $qb > \text{cap}_b$) immediately aborts candidate adoption. Furthermore, empty vehicle partitions ($qa = 0$ or $qb = 0$) are rejected.
2. **Customer Coverage:** Both set identity (`set(cand_all) == expected_customers`) and length (`len(cand_all) == N`) are verified, guaranteeing zero duplicate and zero omitted customer stops.
3. **Monotonic Non-Degradation:** The decision rule is strictly $d_{\text{cand}} < d_{\text{inc}} - \epsilon$. If the candidate is degraded or equal, it is rejected and `inc_opt` is returned unconditionally.
4. **Scope of Proof:** Proposition 1 applies to the two-vehicle subproblem. Because remaining vehicles in the fleet are untouched, $\Delta \text{Fleet} = \Delta \text{Subproblem} \le 0$, preserving global fleet monotonic non-degradation.
