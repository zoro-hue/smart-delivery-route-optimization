## 1. Complete HFVRP-VC Mixed Integer Linear Program (MILP)

- $\mathcal{E} = \{(i, j) \mid i, j \in \mathcal{V}, i

- $\mathcal{K} = \{1, \dots, K\}$: Fleet of heterogeneous vehicles.
- $q_i > 0$: Demand at stop $i \in \mathcal{V}_c$ ($q_0 = 0$).
- $s_i \ge 0$: Service time at stop $i \in \mathcal{V}_c$.
- $d_{ij} \ge 0$: Road network distance from $i$ to $j$.
- $t_{ij} \ge 0$: Base congestion travel time from $i$ to $j$ computed via the BPR power-law function.
- $Q_k$: Payload capacity of vehicle $k$ (kg).
- $	ext{SoH}_k \in [0, 100]$: Battery State of Health percentage of vehicle $k$.
- $	ext{SoC}_k \in [0, 100]$: Current battery State of Charge percentage of vehicle $k$.
- $B_{	ext{nom}, k}$: Nominal battery energy capacity (kWh).
- $V_{	ext{nom}, k}$: Nominal fuel tank capacity (liters).
- $f_k$: Nominal energy consumption rate (kWh/km or L/100km).
- $\mu_k \in [1.0, 1.25]$: Maintenance condition wear multiplier ($\mu_k = 1.15$ for overdue maintenance).
- $R_k$: Usable vehicle operating range (km) calculated from physical state.

### Decision Variables
- $x_{ijk} \in \{0, 1\}$: Binary variable equal to $1$ if vehicle $k$ traverses directed arc $(i, j)$, and $0$ otherwise.
- $y_k \in \{0, 1\}$: Binary variable equal to $1$ if vehicle $k$ is dispatched from the depot, and $0$ otherwise.
- $u_{ik} \ge 0$: Continuous auxiliary variable for MTZ subtour elimination indicating the visit rank of stop $i$ on vehicle $k$.

## 2. Rigorous Proof of Proposition 1 (Conditional Non-Degradation Guardrail)

### Formal Statement
**Proposition 1.** *Let $S_{	ext{ortools}}$ be the initial feasible solution generated by Google OR-Tools. Let $S_{	ext{final}}$ be the output produced by the ROUTE/IQ-NextGen engine. Under identical road network distance matrix $\mathbf{D}$ and fleet constraints, the engine strictly satisfies:*
$$\mathcal{D}(S_{	ext{final}}) \le \mathcal{D}(S_{	ext{ortools}}) + \epsilon_{	ext{float}}$$
*where $\epsilon_{	ext{float}} \le 10^{-4}	ext{ km}$ accounts for machine floating-point precision.*

### Mathematical Proof
1. **Initial Condition:** At initialization cycle $t = 0$, Google OR-Tools executes Guided Local Search (GLS) on graph $\mathcal{G}$, producing solution $S_{	ext{ortools}}$. The solution is verified for feasibility against fleet constraints (payload and range). A deep immutable copy $S_{	ext{baseline}} = 	ext{deepcopy}(S_{	ext{ortools}})$ is stored in memory.
2. **Cooperative Co-evolution:** Over cycles $t = 1, \dots, T$, the candidate blackboard $\mathcal{P}_t$ is populated and mutated by operators $o \in \mathcal{O}$. Let $\mathcal{P}_{	ext{all}} = igcup_{t=1}^T \mathcal{P}_t \cup \{S_{	ext{baseline}}\}$ denote the complete universe of generated solutions.
3. **Stage 5 Evaluation:** The engine identifies candidate $S^* \in \mathcal{P}_{	ext{all}}$ such that:
   $$S^* = rg\min_{S \in \mathcal{P}_{	ext{all}}, \mathbb{I}_{	ext{feas}}(S) = 1} \mathcal{D}(S)$$
4. **Guardrail Logic:** The engine evaluates the deterministic gate:
   $$\Delta = \mathcal{D}(S^*) - \mathcal{D}(S_{	ext{baseline}})$$
   - **Case A ($\Delta \le \epsilon_{	ext{float}}$):** The candidate $S^*$ has distance strictly less than or equal to the baseline (within floating tolerance). The engine returns $S_{	ext{final}} = S^*$. Thus, $\mathcal{D}(S_{	ext{final}}) = \mathcal{D}(S^*) \le \mathcal{D}(S_{	ext{ortools}}) + \epsilon_{	ext{float}}$.
   - **Case B ($\Delta > \epsilon_{	ext{float}}$):** All mutated candidates in the blackboard exhibited higher distance than the initial OR-Tools baseline. The engine triggers the deterministic fallback:
     $$S_{	ext{final}} \leftarrow S_{	ext{baseline}}$$
     In this case, $\mathcal{D}(S_{	ext{final}}) = \mathcal{D}(S_{	ext{baseline}}) = \mathcal{D}(S_{	ext{ortools}})$, which trivially satisfies $\mathcal{D}(S_{	ext{final}}) \le \mathcal{D}(S_{	ext{ortools}}) + \epsilon_{	ext{float}}$.
5. **Conclusion:** Because Cases A and B form an exhaustive partition of all real values of $\Delta$, the inequality holds unconditionally across every execution. $lacksquare$

## 3. Algorithmic Pseudocode

### Algorithm 1: ROUTE/IQ-NextGen Co-Evolutionary Optimization Loop
```python
def route_iq_nextgen_optimize(nodes, fleet, road_matrix, max_cycles=10):
    # Step 1: Initial Classical Baseline
    s_ortools = solve_ortools_guided_local_search(nodes, fleet, road_matrix)
    s_baseline = copy.deepcopy(s_ortools)
    
    # Step 2: Initialize Shared Candidate Blackboard
    pool = CandidatePool(max_size=16, elite_count=4)
    pool.add(s_baseline)
    
    # Generate diverse initial seeds
    s_savings = solve_clarke_wright_savings(nodes, fleet, road_matrix)
    s_sweep = solve_spark_polar_sweep(nodes, fleet, road_matrix)
    pool.add(s_savings)
    pool.add(s_sweep)
    
    # Step 3: Initialize Adaptive Contextual MAB Controller
    mab = ContextualMAB(operators=[
        'qaoa_subproblem', 'qiga_rotation', 'ortools_gls', 'deep_vnd', 'tabu_search'
    ])
    
    # Step 4: Iterative Co-Evolutionary Search
    for t in range(max_cycles):
        state = extract_state(nodes, fleet, pool, stagnation_count)
        operator = mab.select_operator(state)
        parent = pool.select_tournament(k=3, diversity_weight=0.25)
        
        t_start = time.perf_counter()
        child = operator.mutate(parent, nodes, fleet, road_matrix)
        t_exec = time.perf_counter() - t_start
        
        # Evaluate Physical Vehicle Conditions
        metrics = evaluate_vehicle_conditions(child, fleet, road_matrix)
        child.metrics = metrics
        
        # Compute 4-Pillar Multi-Objective Reward
        reward = compute_mab_reward(child, pool, t_exec)
        mab.update(operator, reward)
        
        if metrics.is_feasible:
            pool.add(child)
            
    # Step 5: Proposition 1 Non-Degradation Guardrail
    s_best = pool.get_best_candidate()
    if s_best.distance <= s_baseline.distance + 1e-4:
        return s_best
    else:
        return s_baseline
```
