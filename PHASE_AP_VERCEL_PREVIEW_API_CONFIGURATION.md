# Phase AP: Vercel Preview API Routing & Frontend Configuration

## 1. Overview

This document details the API routing architecture implemented in the frontend to ensure that **Vercel Preview Deployments** communicate exclusively with the isolated staging backend (`https://route-iq-backend-staging.onrender.com`), while **Production Deployments** continue communicating exclusively with the production backend (`https://route-iq-backend.onrender.com`).

---

## 2. Dynamic Runtime API Base Resolution

In [frontend/src/services/api.ts](file:///d:/UROP/smart-delivery-route-optimization/frontend/src/services/api.ts), the static production fallback was replaced with a dynamic, fail-safe environment resolver:

```typescript
// Production and Staging backend endpoints on Render
const PRODUCTION_BACKEND_URL = 'https://route-iq-backend.onrender.com';
const STAGING_BACKEND_URL = 'https://route-iq-backend-staging.onrender.com';

const isBrowser = typeof window !== 'undefined';
const isLocalhost =
  isBrowser &&
  (window.location.hostname === 'localhost' ||
    window.location.hostname === '127.0.0.1' ||
    window.location.hostname === '0.0.0.0');

// A Vercel preview domain has the form: route-iq-frontend-*-projects.vercel.app or contains -git-
// The canonical production domain is: route-iq-frontend-nine.vercel.app
const isVercelPreview =
  isBrowser &&
  window.location.hostname.endsWith('.vercel.app') &&
  !window.location.hostname.startsWith('route-iq-frontend-nine');

const explicitStagingUrl = import.meta.env.VITE_STAGING_API_URL;
const rawApiUrl = import.meta.env.VITE_API_URL || import.meta.env.VITE_API_BASE_URL;

function resolveApiBase(): string {
  // 1. Local development uses Vite proxy to local backend
  if (isLocalhost) {
    return '/api';
  }

  // 2. Vercel Preview Deployments: Route strictly to isolated staging backend
  if (isVercelPreview) {
    let target = explicitStagingUrl;
    if (!target && rawApiUrl && !rawApiUrl.includes('route-iq-backend.onrender.com')) {
      target = rawApiUrl;
    }
    if (!target) {
      target = STAGING_BACKEND_URL;
    }
    console.info(
      `[ROUTE/IQ Preview Routing] Active preview domain (${window.location.hostname}). Directing API traffic to isolated staging backend: ${target}`
    );
    return target.endsWith('/api') ? target : `${target.replace(/\/$/, '')}/api`;
  }

  // 3. Production Deployments (route-iq-frontend-nine.vercel.app): Route to production backend
  const targetProd = rawApiUrl || PRODUCTION_BACKEND_URL;
  return targetProd.endsWith('/api') ? targetProd : `${targetProd.replace(/\/$/, '')}/api`;
}

const API_BASE = resolveApiBase();

const http = axios.create({
  baseURL: API_BASE,
  timeout: 120000,
});
```

## 3. How the Anti-Fallback Guard Works

1. **Detection of Preview Domain:**
   - Evaluated at client runtime: `window.location.hostname.endsWith('.vercel.app') && !window.location.hostname.startsWith('route-iq-frontend-nine')`.
   - Any deployment generated by a branch, PR, or preview build matches this predicate.
2. **Rejection of Production Fallback:**
   - Even if `frontend/.env.production` inlines `VITE_API_URL=https://route-iq-backend.onrender.com`, the resolver explicitly checks `!rawApiUrl.includes('route-iq-backend.onrender.com')`.
   - If the inlined variable is the production URL, the preview resolver ignores it and binds strictly to `STAGING_BACKEND_URL`.
3. **CORS Direct Request:**
   - Because `API_BASE` is an absolute URL (`https://route-iq-backend-staging.onrender.com/api`), Axios sends HTTP requests directly to the staging backend.
   - It bypasses the static `vercel.json` rewrite (`/api/:path*`), avoiding any proxy to the production backend.
   - Backend CORS dynamically permits the request via `CORS_ORIGIN_REGEX=^https:\/\/.*\.vercel\.app$`.

## 4. Optional Vercel Environment Variable Scoping

For customized staging URLs or custom preview domains, environment variables can be configured directly in Vercel:

1. Open [vercel.com](https://vercel.com) $\rightarrow$ Project **route-iq-frontend** $\rightarrow$ **Settings** $\rightarrow$ **Environment Variables**.
2. Add Variable:
   - **Key:** `VITE_STAGING_API_URL`
   - **Value:** `https://route-iq-backend-staging.onrender.com`
   - **Environment:** Select **Preview** only (uncheck Production and Development).
3. Save.
